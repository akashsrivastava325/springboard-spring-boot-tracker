One path. Three ways to study.

Learning path: follow all 204 questions in order. Check a question when you can explain it in your own words.

Complete notes: your full explanation, examples, code, and dry runs. This view only shows items with Complete notes.

Skim notes: short rules, gotchas, and instant-recall hints. This view only shows items with Skim notes. Both views follow your original question order and share the same filters.

Use the red “+ Pre-REQUISITE” button below a question’s notes button to insert a personal question or standalone note immediately before that question. Use “Add your own” to append an item to a section. Edit the title or delete an addition from its note editor. Deleted additions can be undone immediately.

First principles, every time.

Ask: what problem exists → how it works → one tiny example → what changes if I remove it. Use a Student Management application as your running example.

Your data stays with you.

Changes save in this browser on this device. GitHub Pages hosts the application; it does not synchronize your notes. Export backup regularly. Use Import to restore that file on another device. Import replaces the current notebook only after you confirm.

If you move from a preview or downloaded file to the published site, use export/import to move your data to the new address. Clearing browser/site data removes local progress. The app never sends your notes to a server.
